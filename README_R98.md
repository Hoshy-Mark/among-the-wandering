# Cena de integração R98

Abra este `project.godot` no Godot 4.4.1. A cena principal é `demo_inventory.tscn`.

480 identidades persistentes, avatares próximos, rondas na vegetação, combate e persistência residencial. O inventário de contêineres continua na H01. Ativos de cenário e personagem ficam neste projeto; caches, testes e capturas são ignorados pelo Git.

WASD move; Shift corre; I abre inventário; E interage; botão direito mantém mira no ombro; esquerdo dispara; R recarrega. As setas usam os atalhos configurados no inventário.

O nome do projeto mantém o diretório de dados da versão anterior para permitir a leitura do checkpoint R95. O save novo usa `user://demo_population_r98.json`; o arquivo antigo não é sobrescrito. Esta pasta é uma integração local, ainda não um pacote exportado ou publicação atualizada.
